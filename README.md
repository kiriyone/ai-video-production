## 保存方針

作品ごとに `projects/<作品名>/` を作り、概要・工程・学び・根拠を残します。検証結果と提案を区別し、総費用や所要時間が不明な場合は明記します。

このリポジトリは制作ノウハウの文書集です。動画・音声・全生成ログのバックアップや、自動生成ソフト一式ではありません。APIキー、認証情報、一時的な署名付きURLは保存しません。

作品、人物画像、音源、各サービスの公式素材に再利用ライセンスを付与するものではありません。
