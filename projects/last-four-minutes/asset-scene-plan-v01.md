# 最後の4分 — 素材・シーン管理と撮影設計 v01

更新：2026-11-24。脚本第2稿に対応。撮影・生成前の設計であり、完成素材の一覧ではない。

## 参考から取り入れること

ユーザー提供の LAST SIGNAL の画面では、人物・場所・小道具を分け、FOOTAGE をシーン別に整理し、同じ場面の引き・手元・表情や複数テイクを保存している。480pプレビューの表示も確認できる。撮影順、採用率、実際の参照指定、生成モデルや費用はスクリーンショットからは断定しない。

この作品ではその管理方法を採用する。個々の映像やキャラクターを流用するものではない。

## フォルダー設計

- 00_PREPRODUCTION：脚本、尺表、絵コンテ、連続性表、生成記録
- 01_CHARACTER：KEN_CURRENT、MOTHER_CURRENT、AGE_VARIANTS、WARDROBE
- 02_LOCATION：HOME_PRESENT、HOME_MEMORY、PARK、STATION、BIRTH_ROOM
- 03_PROP：PHONE、HOME_ITEMS、MEMORY_ITEMS
- 04_FOOTAGE：SC01〜SC11。シーン内でショット番号・テイク番号を付ける
- 05_AUDIO：DIALOGUE、AMBIENCE、FOLEY、MUSIC
- 06_EDIT_DELIVERY：仮編集、レビュー、完成書き出し、公開用素材
- Watermarks：公式配布素材を保持

ローカルの既存 animatic-v02 は作業ファイルとして保持する。4分割のラフ画像は顔・衣装・間取りの承認済み基準にはしない。
Higgsfield上のフォルダー反映状況は別途実画面で確認する。この文書だけでは作成済みと扱わない。

## 基準素材を先に確定

| 区分 | 最初に用意する素材 | 固定すること |
|---|---|---|
| 人物 | 現在のケン、現在の母：顔正面・斜め・横、体格の正面・背面 | 顔の特徴、髪、体格。年齢は現在ケン32歳・母61歳を仮設定 |
| 衣装 | 人物の隣に置ける服単体の前後図、着用確認 | ケンのグレーの長袖。母の服とエプロンは候補提示後に固定 |
| 年齢差 | 新生児・幼児・小学生・思春期・青年ケン、若い母 | 家族の顔の共通点。母の年齢も年代と一緒に変える |
| 実家 | 人物のいない引き、逆方向、台所、ソファ、簡易間取り | 窓・コンロ・テーブル・ソファの位置、夕方の光の方向 |
| 回想 | 同じ家の過去年代と夜、公園、駅、誕生時の狭い画角 | 現在と共有する家具。全回想を一律セピアにしない |
| スマホ | 前面・背面・側面・手に持った大きさ | ケース、カメラ位置、厚み。通知の文字と数字は編集で合成 |
| 生活用品 | 皿、菜箸、鍋・フライパン、毛布 | 色、材質、使用感、置き場所 |
| 回想用品 | 絆創膏、ろうそく、仕事鞄 | 本当に画面に必要なものだけ作る |

家の世界観は「長く暮らした普通の実家」。磨かれた展示室にはしない。食器の不揃い、使い込んだ家具、毛布の擦れなど、母子の時間が感じられる程度に生活感を置く。

### SC06 走馬灯

M01 誕生2秒／M02 最初の一歩1.5秒／M03 水遊び1秒／M04 絆創膏1.5秒／M05 誕生日1秒／M06 反抗1.5秒／M07 友人との写真1秒／M08 駅で涙1.5秒／M09 毛布2秒／M10 今日の母の問い3秒。合計16秒。

まず10枚の静止画と仮の音で確認。短いカットで分からない情報は削る。誕生は布に包まれた赤ん坊と母の手・胸元だけで伝える。
回想中も現在の時計は進む。2:04で残り02:06に戻る。

### SC08 母の理解を伝える撮影順の設計

- A：母の視点のスマホ。「最終通知」「ケン」「残りの寿命」が読める。
- B：母の顔。「最終通知……あなたの？」視線が画面からケンへ移る。
- C：ケンの小さなうなずき。母の問いへの返答でつなぐ。
- D：母が画面へ戻り、停止操作を試みる手元。ケンの「変えられないって」。
- E：手が止まる。母が頬に触れ、まだ温かい息子を見つめる。
- F：「ここにいて」を聞く母。一拍置いてうなずく。
- G：コンロを切り、菜箸を置く。料理の音が弱まる。
- H：前腕に触れて「座ろう」。スマホはテーブルに残し、二人はソファへ。

A→B→Cで「何を理解したか」、D→Eで「受け入れられない気持ち」、F→Hで「息子のそばにいる選択」を示す。
全てを顔アップにせず、途中に二人の位置が分かる画を確保する。

## 生成と編集のルール

1. 基準画像を選定してから、人物・衣装・場所・小道具の参照を各ショットにひもづける。
2. 最初にSC08の重要部分を絵コンテで確認。母の理解が伝わるかを先に検証する。
3. 1ショット1動作を基本に、演技の開始状態・動作・終了状態、視線、持つ手、カメラを記す。
4. モデルで利用できる場合は480pなどの下書きで確認。採用候補だけ本生成する。対応解像度や費用は実際の生成時に確認。
5. 複数テイクは顔・手・演技など具体的な問題を直すために使う。参考作品の生成数を目標にしない。
6. シーン内の左右、スマホの向き、母の持つ菜箸、火の状態、ソファで握る手を連続性表に記録。
7. カット頭と末尾に編集の余裕を確保。つなぎは動作と視線、音を優先し、トランジションで破綻を隠さない。
8. SC10は母の返事をケンが生きて聞き、握り返すまで見せる。その後に00:00へ進める。

## ファイルと生成記録

命名例：SC08_SH03_T02_preview.mp4
SC＝シーン、SH＝カット、T＝テイク。走馬灯はSC06_M01などを使用。
同じシーンフォルダーに静止画・下書き・採用版を置いても、名前と台帳で区別する。

台帳の項目：
シーン／カット／目的／参照素材IDと版／プロンプト／モデル／生成日時／ジョブID／解像度／生成尺／実使用尺／テイク／費用またはクレジット／採否／問題と修正理由／保存先。
不明な費用や使用モデルは推定で埋めない。失敗テイクも採否と理由を残す。

## 着手順

現在のケンと母の人物基準 → 別の衣装シート → 実家の間取りと空の画 → スマホと生活用品 → SC08の絵コンテ → 小規模な動作テスト → 年齢別素材と走馬灯 → 全体の仮編集。
人物・衣装・場所はまだ選定前。シーン動画を先に大量生成しない。
