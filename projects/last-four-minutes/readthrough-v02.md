# 第2稿：会話・間・走馬灯の点検

2026-11-24 / America/Chicago

## 確認方法と限界

脚本を発話順と反応の順に読み、重複、言葉の意味、沈黙の理由、場面ごとの変化を点検した。
音声の再生・収録による読み合わせは実施していない。「自然に聞こえた」「4分20秒に実測で収まった」とは扱わない。
次は台詞と生活音を置いた仮編集で検証する。今回の第2稿はユーザーの最終承認前。

## 第1稿の課題と変更

| 課題 | 第2稿での対応 | 次に確認すること |
|---|---|---|
| ご飯の聞き違いが繰り返され、母が鈍感に見える | 二度目の聞き違いを削除。母は「どうした？」と聞くが、ケンが引っ込める | ケンの言えなさに共感できるか。単なる引き延ばしに見えないか |
| 通知の操作に30秒、言い出せない場面に40秒あり、似た動作が続く | それぞれ20秒、30秒へ短縮。余分な独り言も削除 | 通知の文字を読める時間を確保できるか |
| 母が一瞬で死を受け入れ、賢い聞き役になりすぎる | 名前と「残りの寿命」を画面に表示。「最終通知……あなたの？」→否定→止めようとする→頬に触れる→息子に求められてそばにいる | 音なしでも画面と表情から理解できるか。母が平然として見えないか |
| 「いつものでいい」が、いつもの会話回避を勧めるようにも聞こえる | 「うまく言わなくていい」に変更 | 母の言葉として自然か。名言のような読み方を避ける |
| 感謝に至る人生の厚みが乏しく、二人の重要性が設定頼み | 1:48から16秒、誕生から現在まで10カットの走馬灯 | 母だけの思い出集ではなく、ケンの生きた人生に見えるか |
| 最後の長い沈黙が同じ表情の反復になる可能性 | 怖い→手を取る→呼吸→母を見る→ありがとう→返事→握り返す、と行動で区切る | 演技時間を実測。無理に声を遅くしない |

## 走馬灯を中盤に置く理由

最期に記憶を全部入れると、母の返事を聞く瞬間と競合する。
冒頭すぐでは、観客がまだケンも母も知らないため、人生の映像集に見えやすい。
「いつもそうね」で始め、冒頭の「今日、どうだった？」を見直して現在へ戻れば、ケンがスマホを見せる選択に結びつく。

産声、初めの一歩、遊び、擦り傷、誕生日、反抗、友人、孤独、毛布、今日の母。
悲劇を増やすための事故や誰かの死は追加しない。日常の喜びと痛みを短く積み重ねる。
楽しかったからこそ失いたくない、つらい日にも母はいた、という両方が最後の「怖い」「ありがとう」につながる。

## 仮読み・仮編集の順序

1. 台詞を通常の速さで読む。母と息子を聞き分けられればよく、最初から本番音声を全量生成する必要はない。
2. まず台詞・呼吸・行動を置き、無音を足して4分にする作業を避ける。10秒ごとの枠へ無理に合わせない。
3. 走馬灯をラフ10枚と短い音で16秒に仮組み。最初2秒・最後3秒を読み取れるか確認する。
4. 直後の「これ、見て」が自然に出てくるか確認。
5. 母の場面は通知画面を見せる版で確認。「いつから？」だけの旧版に戻さない。
6. 初見の人に、事前説明なしで「通知は何か」「母はいつ分かったか」「ケンは何を選んだか」を自由回答で聞く。正解を先に教えない。
7. 「ありがとう」の返事をケンが聞いたこと、ゼロ以後に本当に死んだことが伝わるか確認。
8. 尺が余るなら静止顔を増やさず構成を見直す。4分リアルタイムの条件を変える場合は、その変更を明示する。

## 現時点の判断

走馬灯を加える方向は物語の理由がある。ただし、速い映像を加えるだけで感情が深くなるとは限らない。
採用判断の要点は、回想後のケンの行動が変わること、母が人間として動揺すること、最後に現在の二人へ集中できること。
