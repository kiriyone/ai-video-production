# 最後の4分

死の最終通知が届いた男。残された四分で、いつも後回しにしていた母との会話を始める。

- 制作者：Velichan
- 更新：2026-11-25 / America/Chicago
- 工程：承認済みv05の映像を保持し、日本語の混入音声を修正した英語字幕付き全編 v01を制作済み。
- 結末：母に感謝が届き、ケンの主観で母を見つめながら視界が閉じる。
- 現在の全編尺：4分15.625秒。最初の04:00から閉眼・00:00まで実時間4分。
- 前版v04：ユーザーは修正後を評価。全編19〜20秒、51〜52秒の2か所に残る跳びを指摘し、ほかの箇所は問題ないと確認。v05でその2本の画角だけを補正した。
- 次工程：英語字幕・修正音声の通し試聴、音響・声の統一、高画質化、応募用マスター。
- 予算：記録済み累計938.75クレジット、実残高1,851.63。今回42。前回残高との差176.75は今回作業前に発生した未照合差額。追加購入なし。
