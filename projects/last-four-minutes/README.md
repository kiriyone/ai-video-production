死の最終通知が届いた男。残された四分で、いつも後回しにしていた母との会話を始める。

- 制作者：Velichan
- 更新：2026-11-25 / America/Chicago
- 工程：冒頭から閉眼・メッセージまでの全編ラフを制作済み。現在は冒頭の残り2か所を補正した v05。
