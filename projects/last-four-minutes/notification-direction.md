# 通知・時計・音の演出方針

更新：2026-11-24。『最後の4分』現行脚本に適用。カウントの常時表示はしない。

1. 通知直後は短い振動音→手持ちスマホのアップ→ケンの反応。文字・数字は編集合成。
2. スマホの存在を示した直後に限り、左側へ画面を短く残す。顔・視線・手の芝居を隠さない。
3. 母子の会話へ戻る時点で画面表示と前面の時計音を引く。時間は進行しており、表示を消しても停止・巻戻し・リセットしない。
4. 母は最初、料理中で通知画面を見ていない。「四分」を調理の話と受け取る。ただし通知の全文が母にも明瞭に聞こえる音場だと不自然になる。台所の距離・向き・換気扇と、ケン側のスマホ音の近さでこの違いが伝わるか試写確認する。効果音で台詞を隠して解決したことにしない。
5. 走馬灯は誕生から現在までの記憶へ集中させる。常時時計や秒刻みの音で画面を埋めない。
6. 残り時間を再提示するのは物語上の節目。全編仮編集で必要箇所を選ぶ。
7. 最後の言葉が届く瞬間は顔・声・呼吸を優先。数字の大写しや大音量で感情を中断しない。
8. 本編は通知0:10／死亡4:10の計画。単独試作の長さをそのまま加算しない。生成した台詞の実測に沿って本編を再編集する。

現在は480p素材を使う演出試作。声の自然さ・話者割当・間・理解の確認後に本番画質化する。
