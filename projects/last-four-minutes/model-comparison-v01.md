# 人物・ロケーション統合とモデル比較 v01

2026-11-24。『最後の4分』現代の実家・冒頭の1カット。2枚生成、動画未生成。ユーザー最終承認前。

## 比較目的と条件

Nano Banana Proに部屋・ケン・母・ケン衣装・母衣装の5枚を参照させて統合。その完成画像1枚をSoul Cinemaに渡し、同じ画角・配置・人物・衣装・ポーズのまま質感のみ改善するよう依頼した。
同じ入力条件のモデル性能比較ではなく、Nano Banana Pro→Soul Cinemaという追加工程の価値を検証する試験。各1枚なのでモデル一般の優劣は断定しない。

## 結果

### Nano Banana Pro：修正の土台に選定

![Nano Banana Pro](https://d8j0ntlcm91z4.cloudfront.net/user_3MWSCps0p62bmHjscdjaGWcafIT/hf_20261124_231730_6ee9dd60-0214-4b91-b3a1-ae6c69771d9e.png)

- 左のソファと窓、奥左の廊下、右奥の台所、食卓1つ・椅子2脚の大きな配置を維持。
- ケンの金髪と母の低い結び髪、黄色・マゼンタのパーカー、ベージュのカーディガンと青灰のエプロンを引きの画で識別可能。
- 母がケンを見る一方、ケンはスマホを見る。冒頭の注意の距離が読める。
- 衣装柄は基準から簡略化。母の白髪と年齢感、顔の細部は寄りで再確認が必要。
- 指示との差分：ケンは両足接地ではなく脚組み、右手持ちではなく両手持ち。手順・持ち手の基準にはまだしない。
- 食卓のマグとティッシュが消失。基準全景との小道具連続性は未完成。
- 人体が床・ソファに置かれているように見えるが、立ち上がりや母の通路は動画で未検証。

### Soul Cinema追加工程：このカットには不採用

![Soul Cinema](https://d8j0ntlcm91z4.cloudfront.net/user_3MWSCps0p62bmHjscdjaGWcafIT/hf_20261124_232008_88082951-225a-4bac-b21f-610365624ffe.png)

- 暗めの色調と質感、画面内の奥行きは生まれた。
- しかしケンが短髪になり顔も変化。母のエプロンの色・長さ・服装、髪や年齢の見え方も変わる。
- 大きな柱・壁が追加され、冷蔵庫が右端から中央寄りへ移動。窓、台所、食卓、ソファの形やカメラ位置も変化。
- 「同一人物・同一場所の質感改善」という今回の条件を満たさないため、本番の連続カットや基準参照には使わない。

## 今回の判断

既存のGPT Image版は部屋の配置基準として保持。人物と衣装の統合は今回のNano Banana Pro版を修正候補にする。Soul Cinemaを全画像へ自動的に追加する工程にはしない。
印象の良さだけでなく、顔・衣装・間取り・動作が維持されるかで採用を判断。新たなロケーションの雰囲気探索など別用途の適性は未検証。

## 次に直す順番

1. Nano Banana Pro版を参照し、ケンの両足接地・右手スマホ・左手を腿へ戻す。衣装シートを添え、柄を揃える。顔や部屋を変えない。
2. 食卓の小道具は元のマグ・ティッシュを戻すか、撮影用全景からも外すかを統一する。勝手に消失した状態を確定扱いしない。
3. スマホの形状と画面向き、母の調理位置・通路を確認。人物寄りで顔と母50歳の年齢感も確認する。
4. 修正静止画からSeedance 2.5の短い480p下書きを1本作り、母が振り向く・ケンが返事をして目を戻す、の自然さを仮音声と確認する。次の動画生成はこのターンでは未実施。
