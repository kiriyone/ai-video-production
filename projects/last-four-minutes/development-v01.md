# 「最後の4分」企画を詰めるための提案 v01

2026-11-24 / America/Chicago  
状態：検討案。元の01-brief.mdは保持。結末はユーザーと相談中。素材生成・音声生成は未着手。

## 残したい核

「自分には人生最後の4分。でも家の中は、いつもの夕方のまま。」

死の宣告と夕飯の支度の落差を笑いにし、その日常が最後には愛情として見える構造にする。主人公が「あと4分」を繰り返すだけのコントにはしない。

## 元案で先に直したい点

1. テーマは「大事なことに気づけない」なのに、結末では気づいて感謝を伝えている。今回の提案では「大切なことほど、いつでも言えると思って後回しにしてしまう」に統一する。
2. 天気、焼肉、猫、ラッキーカラーが独立したボケになっている。すべてを残すと主人公の目的が見えにくい。
3. 母が死の宣告を理解しながら無視すると、感情の結末より冷酷さが残る。序盤は料理の音や言いよどみで聞き取れず、終盤は異変に気づいて本当に聞く人物にする。
4. スマホの発言を主人公が即座に信じる理由が未設計。最初に疑い、止める・確かめる行動を置く。
5. 2:40時点で残り1:30、3:30時点で残り0:10という元案の表示は、実時間と一致しない。台詞内の「あと4分」も更新する。
6. 「生きてたよ。ちゃんと」は、それに対応する問いや出来事がないと抽象的。残すなら前半に意味を作る。台詞の雰囲気だけでは採用しない。

## 推奨する人物と欲求

- ケン：30代。普段、母の問いに「普通」「あとで」と答える。感情を言葉にするのが苦手。
- 母：料理中。忙しいが冷たくはない。小言の中に気遣いがある。
- 通知の声：丁寧で事務的。人間の事情に応じない。

画面に出る人物はケンと母の2人。友人と猫はいったん外す。場所は連続したリビングと台所。
最初の目的は通知を取り消すこと。中盤で、母に言葉を届けることへ変わる。

俳優名・演技理論名を生成指示の代わりに使わず、目的、視線、指、息、姿勢と反応の順に分解する。添付の理論説明や引用は、この企画で事実確認した資料として扱わない。

## 世界のルール（提案）

死の通知が届く不条理な世界として描く。医学的予測の実演にはしない。起源を長く解説しない。
通知を消すことと、残り時間を増やすことは別。画面を閉じても時間は減る。

これを観客が受け入れられるかは最初の30〜45秒の読み合わせで確認する。必要なら短い視覚的な異変を1つ足すが、設定説明・新たな登場人物は増やさない。
結末を「実は誤通知」にする場合は、このルールと伏線を最初から書き直す。最後だけ故障と言って逃げない。

## 笑いを主人公の行動につなげる

以下は新規提案の会話。まだ完成脚本ではない。

ケン「これ、キャンセルできる？」
通知「通知はオフにできます。」
ケン「通知じゃなくて。」

通知を止めようとしたケン自身の目的から笑いを作る。

母「ちょっと、手を貸して。」
ケン「今、時間ない。」
母「いつもそうね。」

この一言のあと、ケンはタイマーから母へ目を移す。「最後だから忙しい」自分と、普段も同じ返事をしていた自分がつながる。ここを中盤の転換にする。

## 約4分20秒の構成案

厳密な4分の残り時間は、本編0:10から4:10まで。最初10秒の関係紹介と最後10秒の余韻を別に取る。クレジット・公式エンドは別。
時刻は設計値。実音声・芝居の長さで調整し、カウントダウンは編集の最終タイムラインから計算する。

| 本編時刻 | 残り時間（区間冒頭） | 出来事と変化 |
|---|---|---|
| 0:00–0:10 | 開始前 | 母「今日どうだった？」ケン「普通」。顔を上げずに返す普段の関係 |
| 0:10–0:40 | 4:00 | 死の宣告。まず疑う。通知を閉じ、再び開くと30秒減っている |
| 0:40–1:10 | 3:30 | 取り消しを試みる。「通知じゃなくて」。AIの丁寧さに苛立つ |
| 1:10–1:50 | 3:00 | 母に言おうとするが調理音と自分のためらいで届かない。母は夕飯の話だと思う |
| 1:50–2:30 | 2:20 | 「今、時間ない」「いつもそうね」。自分もいつも会話を避けていたと気づく |
| 2:30–3:10 | 1:40 | ケンは通知を操作するのをやめ、母のそばへ行く。母が異変を察して作業を止める |
| 3:10–3:40 | 1:00 | 母「どうしたの」。初めて向き合う。ケンは立派な最期の言葉を作ろうとして言いよどむ |
| 3:40–4:10 | 0:30 | 本音を言い、母が受け取る。ゼロになる結果は結末選択で決める |
| 4:10–4:20 | 0:00以後 | 冒頭の日常音・問いの意味を変えて終える。説明ナレーションは入れない |

「今日どうだった？」という問いへの返事を、最後に「普通」ではない本音へ変える。
台詞候補は「……怖い」「うん。ここにいるよ」。感謝を残す場合は、その後の短い「ありがとう」まで。
「生きてたよ。ちゃんと」を必須にはせず、母との会話として自然かで判断する。

## 結末の3方向（未決定）

### A：本当に時間が尽きる — 元案に近い推奨候補

母が本音を受け取り、そばにいると伝える。ゼロの後にケンは返事をしない。母の反応で時間切れを伝え、派手な倒れ方や大音響に頼らない。
死亡を選ぶなら「画面が暗くなっただけ」で済ませず、観客に結果が伝わる演出を設計する。
「言い終わる前に死ぬ」より「言葉は届いたが、時間は止められない」の方が主人公の選択を残せる。

### B：生き残る — ブラックコメディ

ゼロ後も生きている。告白だけは取り消せず、母子の関係が変わって残る。
ただし誤通知なら、その兆候を前半から提示する。通知の誤りの理由・回収を決めるまでこの結末は確定しない。

### C：生死を断定しない — 不穏な余韻

ゼロの直前で暗転し、母の返事を残す。観客の解釈に委ねる。
作りやすい反面、約束した結末から逃げた印象になりやすい。曖昧さそのものが作品のテーマになる場合に選ぶ。

## 映像と音の方向

- 前半：生活感のある明るい夕方、固定の少し広い画。通知と返事の間で笑いを作る。
- 中盤：タイマーのアップを増やすより、ケンが母を見る時間を増やす。
- 後半：母が調理を止めると、日常音が減る。そこで初めて2人の声がはっきり届く。
- 前作の暗い食卓・肉・不穏な微笑みと差別化する。今回は生活の温かさと、言葉が届く瞬間を撮る。
- スマホ数字は生成映像に任せず、固定の画面素材と編集上の表示で正確に管理。採用する応募規約に合う方法か実行前に確認。
- 接触する手、スマホ画面、母子の2ショットは先に短い下書きで確認。複数の皿や猫のアクションは増やさない。
