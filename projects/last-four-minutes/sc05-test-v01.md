# SC05 — いつもそうね（仮演技テスト v01）

制作日：2026-11-24 / America/Chicago

## 演出

母にとってはいつもの夕飯、ケンにとっては残りわずかな時間。「今、時間ない。」が、普段の断り文句にも現在の切迫にも聞こえる場面。母を冷たい人物にしない。

| 指定時刻 | 台詞・動き |
|---|---|
| 0.4–2.8秒 | 母「そこにいるなら、お皿、出して。」料理をしながら何気なく頼む。 |
| 3.2–4.2秒 | ケン「今、時間ない。」反射的に返す。怒鳴らない。 |
| 4.8–5.9秒 | 母「いつもそうね。」軽い小言。皮肉や敵意を込めない。 |
| 6–8.2秒 | ケンが左手のスマホを少し上げて見てから、母の背中を見る。 |
| 8.5–9.3秒 | 母「ケン？」息子の沈黙に気づき、少し振り向く。 |
| 9.3–12秒 | ケンが母を見る。返事はなく、小さな息。走馬灯へつなぐ余白。 |

時刻と台詞は生成への指定であり、実際の発話内容・時刻の検証結果ではない。
