# SC02 通知のつなぎ・音響比較版 v02

作成：2026-11-24。ユーザー指摘：浮かぶ文字パネルが説明的。通知を受けてスマホ画面が映るつなぎと切迫する音が必要。

## 変更
- 旧サイドパネルを外し、実際に両手で持ったスマホの主観アップを挿入。
- 黒いガラス面へ「最終通知」「ケン」「残りの寿命」と大きな秒表示を編集合成。
- フォントはBIZ UDゴシック＋Bahnschrift。文字を生成モデルに描かせない。
- 独自合成した短い振動、下降する電子通知音、毎秒の低い打音と薄い持続低音。既成音源のサンプリングなし。
- 元動画の未聴取音声は今回の比較版には混ぜず、作成した仮効果音トラックを使用。生活音・通知の声・会話は次の音声編集で合わせる。

## 7秒の試写タイムライン（24fps）
- 0.000–0.625：既存ケン映像の冒頭15フレーム。0.24／0.43秒に短い振動音。
- 0.625–4.000：スマホの静止画81フレームに緩い寄り。04:00から1秒ごとに03:59、03:58、03:57。
- 4.000–7.000：既存ケン映像の1.0–4.0秒。小さな笑みが消える反応。
- 毎秒の打音は0.625秒起点で同期。これは単独の比較版。本編0:10通知／4:10死亡の連続計時は仮編集で再調整する。

## 確認と未確定
- MP4は7.000秒／1280×720／AAC音声。ケン部分の元素材は480pであり、720pの新規高画質生成ではない。
- 画面合成位置、03:59の読める表示、スマホの輪郭と両手、表情へ戻る並びを静止画で確認。
- 音は波形・トラック存在・音量を検査。ピーク約-9.5dBFS。聴感、切迫感、音量バランスの最終判断はユーザー試写待ち。
- 手元は静止画＋緩い寄り。腕・座り方（開いた膝と既存の脚組み）、背景の視点は連続性の要調整。完成素材として固定しない。
- 会話、通知の声、部屋の生活音は未合成。タイムライン全体の時間整合も未検証。
