# 実際に起きた問題と、採用した判断

物語の結末に関わる記述を含みます。

| 問題 | 対応・結果 | 次回に残す判断 |
|---|---|---|
| 寝室のドアが不自然に半分しか閉まらない | 記憶カットの芝居と閉鎖を修正 | 扉の動作を画面外の想像だけに任せない |
| 収納の扉が開口と合わない | 3コマの時間順参照で右区画と右扉の関係を固定。480p下書きで開口を覆う状態を確認 | 形状と接触は静止絵コンテの段階で検査 |
| 包丁が宙に浮く | 右手で柄、左手でドアという役割を明記。確認区間で浮遊は見られなくなった | 小道具を持つ手を途中で曖昧にしない |
| 過去の記憶に見えず恐怖も弱い | 芝居・構図・色・音の差を見直した | 暗さだけで「過去」「恐怖」を表現しない |
| カット切替がカクカクする | 短いフェード、記憶の暗転、音の余韻を調整。冒頭は後に連続9秒ショットへ置換 | つなぎの問題は元の芝居から直す場合もある |
| カメラが平板 | 抑えた寄り、反応や決定的な物への再構図 | 編集の寄りを生成ドリーの成功例と偽らない |
| 手洗いに血がない | 血の残りを洗う画へ修正 | 物語上必要な情報は参照素材にも入れる |
| 説明が重い | 手洗いから推測できるため「I killed you yesterday」を音声・字幕ごと削除 | 画で分かることを台詞で復唱しない |
| 食卓の不気味さが足りない | 肉のカットを10秒にし、緩やかな寄りと既存音楽の不協和な層を追加 | 観客に気づく時間を渡す |
| 座って一息つく場面が重複 | 旧2:06.75–2:12.75の6秒を削除 | 好きなカットでも同じ役割なら切る |
| 終わりの6秒動画で皿が滑る | その動画は不採用。生成基準画像を6秒固定し、椅子の軋みから最後の笑みへ | 動かさないという選択も完成手段 |

## 動画エレメントは万能ではなかった

静止画参照Aと動画参照Bを、各5秒で比較した。Aは口元の緊張から右へ視線が動く変化を読み取りやすかった。Bには参照のまばたきや口の動きが強く残り、必要な視線移動が弱かった。この場面の暫定候補はA。

各1テイク、seed固定なし。参照方式だけが差の原因と確定した比較ではない。
抽出画像で顔の大きな変形がないことと、演技が自然であることは別。
SSIM等の画像類似度は演技の自然さの点数にはしない。

動画参照は、欲しい芝居がすでに入った素材を用意できた場合に試す。
このテストではCinema StudioのElements登録、声クローン、対話口パクの検証は実施していない。紹介されていた機能を全部試したように書かない。

## 音と間で成立させた最後の6秒

完成v5の本編内時刻：
- 2:47–2:53：空席の生成静止画を保持。
- 2:49まで：BGMを引く。
- 2:49.5–2:51.05：椅子の軋みを一度。
- 2:53–3:00：承認された控えめな笑み。
- 3:00–3:08：クレジット。

動くテイクを使わなかった事実まで残す。これは生成映像の品質が勝手に上がった話ではなく、編集で怖さと物理的整合性を優先した話。

## 次作へ持ち越すこと

少数の重要カットで接触・遮蔽を先に検証する。良い演技参照だけを使う。低解像度の成功と最終画質を区別する。
音のための空白を残し、1シーンが一つ前と違う情報を伝えているかを確認する。
