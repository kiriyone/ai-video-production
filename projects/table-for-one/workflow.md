# 制作工程と次回用チェックリスト

今回の記録から再利用できる進め方。以下のプロンプト欄は次回用に整理したテンプレートで、過去に送った全文そのものではありません。

## 1. 何を感じさせるかを決める

主人公の欲求、障害、最後の変化を一文ずつ書く。場面の入口と出口で、観客の理解が変わるか確認する。
今回の欲求は静かに一人で食事をすること。障害は父親の声と身体に残った習慣。終盤の食卓と笑みで、その行為の見え方を変える。

説明台詞から作るより、電話を止める・もう一枚の皿を置く・空席を見る、といった行動を決める。

## 2. 同じに保つものを別々に用意する

- 人物：顔、正面・側面・背面。実写風の質感と体格。
- 服：人物の隣に、衣服単体の参照を配置。袖・色・素材を確認。
- 場所：人物のいない基準画。玄関、食卓、台所、収納、寝室の位置関係。
- 小道具：電話、皿、包丁。大きさ・置き場所・持つ手を固定。
- 絵コンテ：開始・途中・終了の3コマ。各コマの扉・手・道具の状態が物理的につながるか先に確認。

素材の分類は人物／衣装、場所、小道具、絵コンテ／基準画像、映像、音、完成版、旧テイクに分ける。
今回整理した97件は素材件数であり、失敗回数や完成カット数ではない。

## 3. 接触する芝居は3コマ参照から小さく試す

絵コンテは「コラージュを映す開始画像」ではなく、連続ショット内の時間順として説明。
人物・小道具の参照を併用し、扉の開口、取っ手、左右の手、遮蔽を指定する。

次回用の指示項目：
- 観客がこのカットで発見すること：
- 開始状態：
- 中間の動作：
- 終了状態：
- 右手が持つもの／左手が触るもの：
- 動かさない物・変えない形：
- カメラの高さ・画角・動き1つ：
- 音のきっかけ：
- 採用判定：

棚の例：左扉は閉じたまま、右区画に皿を置き、右扉がその開口を覆って閉まる。
寝室の例：右手で包丁の柄を保持し、左手でドアを閉める。包丁は手から離れない。

## 4. 下書きは見栄えより動作を検査

今回の3コマ参照テストは480pで生成。低解像度では指先の完成品質は判断しない。
全体を数fpsで抽出し、持ち手や閉鎖の問題区間は元フレーム単位の拡大一覧で確認した。

- 扉は開口に合う寸法か。閉まった瞬間に形が変わらないか。
- 手と包丁の柄が離れないか。手が物を貫通しないか。
- 皿が勝手に滑らないか。置いた物が次のカットにもあるか。
- 前後カットの左右、衣装、照明、視線がつながるか。
- 下書きの仮音を、そのまま最終音と判断していないか。

採用した動作を高解像度化しても、同じ成功が保証されるわけではない。完成テイクでも再確認する。

## 5. 仮編集を早く作る

良いカットを集めるだけでは、同じ動作が重複する。今回、座って一息つく場面を6秒削除。
冒頭の不自然なつなぎは、トランジションだけでなく連続9秒のショットへ置き換えた。

寄り・固定・間を使い分ける。編集上のデジタルズーム／再構図と、生成したカメラ移動は区別して記録する。
フェードを全カットに一律適用せず、記憶への暗転など意味がある箇所に使う。

## 6. 音は別レイヤーで仕上げる

声、部屋の環境音、動作音、BGMを分ける。声の速度・ピッチを不用意に変えない。
今回の仕上げでは既存AI音楽を5つのキューに再配置し、台詞中は下げ、音楽を抜く区間を作った。
最後の空席では椅子の軋みを一度だけ鳴らす。音を増やすより、音楽を引く余白を作る。

音割れや同期の測定に合格しても、怖さや聴きやすさを承認したことにはならない。最終版を耳でも確認する。

## 7. 仕上げと公開

- 英語／日本語字幕の読める位置、タイミング、端の余白を確認。
- タイトルを中央へ配置。意味のある180秒の本編とクレジット等を分けて計測。
- 公式の透かし・エンド映像は指定素材を使用。サービス側の自動追加との二重表示を確認。
- 全編デコード、映像・音声の長さ、クリップ、字幕を検査してから視聴レビュー。
- 公開タイトル、短い紹介文、作品説明を現在の作品に合わせる。旧企画名を残さない。
- YouTube公開、Higgsfieldプロジェクト公開、コンテスト最終応募の3状態を別々に記録。
- 応募条件・締切は応募時点の公式画面で再確認。過去のメモを現行規約と扱わない。
