## 作品と現在地

TABLE FOR ONE / 一人分。英語音声・英語字幕の心理ホラー。日本語字幕版も保存。
物語180秒＋クレジット8秒。公式エンド映像を加えたYouTube版は約3分20秒。

主人公は、一人で食事をしたい。しかし父親からの声が、抜け出したはずの服従の習慣へ引き戻す。
テーマは「相手を消しても、身についた恐怖は消えない」。

YouTubeとHiggsfieldのプロジェクト公開に加え、2026-11-24にユーザーが投稿確認完了を報告。Talent Contestの応募作品一覧に「TABLE FOR ONE」、作者「velichan」、尺「3:08」が表示された画面を確認しました。応募一覧への掲載を確認済みとして記録します。これは適格性審査通過・最終候補選出・受賞を示すものではありません。

## 最も大きかった学び

きれいな1カットと、つながる物語は別の問題でした。普通の扉が閉まる、包丁を握り続ける、皿が動かない。こうした小さな連続性が崩れると、怖さより違和感が先に来ます。

最後の空席6秒は、動く生成を不採用にし、生成静止画と椅子の軋みで成立させました。「動かすこと」より「観客に何を想像させるか」を選んだ具体例です。
