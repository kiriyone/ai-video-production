# 次の動画を始める

`video-project/` の中身を `projects/<作品名>/` にコピーして使います。まずコピー先のREADMEに作品名と現在の工程を書き、01から順に埋めてください。短い動画では不要な項目を「対象外：理由」として省略できます。

## 進め方

| 段階 | 記入するもの | 次へ進む目安 |
|---|---|---|
| 企画 | [01 企画](video-project/01-brief.md) | 誰に何を見せ、最後に何が変わるか決まった |
| 脚本・素材 | [02 脚本](video-project/02-script.md)、[03 素材](video-project/03-assets.md) | 人物・服・場所・道具の基準がそろった |
| 生成 | [04 ショットとプロンプト](video-project/04-generation.md)、[テイク表](video-project/takes.csv) | 下書きで動作とつながりを確認した |
| 音・編集 | [05 音と編集](video-project/05-edit-sound.md) | 全編がつながり、必要な音と間がある |
| 完成確認 | [06 品質確認](video-project/06-review.md) | 指摘と修正を照合し、完成版を再生した |
| 公開 | [07 公開](video-project/07-release.md) | 公開URLと表示・再生を確認した |
| 振り返り | [08 制作記録](video-project/08-retrospective.md) | 失敗、費用、時間、次回の改善を残した |

工程の「目安」は制作上の確認点です。追加の承認フローを自動的に課すものではなく、ユーザーが指定した範囲・予算・公開方針に従います。

## ファイルのルール

- 素材ID：人物 C01、衣装 W01、場所 L01、小道具 P01、音 A01。
- ショットID：S001。テイクID：S001-T01。編集の版：v01。
- 例：`S001-T01-draft.mp4`、`S001-T02-final.mp4`。再生成したら上書きせず別テイクにする。
- 素材本体・録画・認証情報はローカルに置き、公開可能な参照先だけを文書に記載する。
- このテンプレートは特定サービスの現行仕様・応募規約を保証しない。モデル、対応解像度、費用、利用条件は実行時に確認する。
- テンプレートの空欄は未実施。埋まっていることと、確認済みであることを区別する。
