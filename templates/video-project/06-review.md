## 確認項目

- [ ] 冒頭で興味・状況・問いが伝わる
- [ ] 場面ごとに変化があり、説明や動作の重複がない
- [ ] 顔・服・体格が維持されている
- [ ] 視線、画面の左右、部屋の配置が前後でつながる
- [ ] 扉の寸法・閉まり方・手と道具の接触が自然
- [ ] 道具が浮く、皿が滑る、物が突然消える現象がない
- [ ] 血や汚れ等の状態変化が物語と一致
- [ ] 台詞が聞き取れ、音割れや不自然な無音・途切れがない
- [ ] 字幕の内容・位置・タイミングが最終台詞に一致
- [ ] タイトル、クレジット、必要な公式素材が読める
- [ ] 最初から最後までファイルを再生できる
- [ ] 音声と映像の同期、尺、解像度、fpsを確認
- [ ] 別言語版・抜粋版もそれぞれ確認
